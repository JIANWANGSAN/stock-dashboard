## 一、换一台电脑，怎么跑起来（3 步）

> 前提：装了 Python 3.10+（[python.org](https://www.python.org) 下载，安装时**务必勾选 Add Python to PATH**）

1. 把整个文件夹拷到新电脑（或 `git clone` 本仓库）
2. **双击 `setup.bat`** —— 自动建虚拟环境并安装 `pypinyin`（只做一次）
3. **双击 `refresh.bat`** —— 抓数据，完成后打开 `index.html` 即可

数据抓取只依赖 Python 标准库 + `pypinyin`，无其他第三方依赖。

## 四、核心口径（改代码前必读）

- **股票池过滤**：一律剔除 北交所（4/8/92 开头）、科创板（688/689）、ST / 退市
- **连板高度梯队**（**单条连续折线 · 2026-09-23 用户两次澄清后的最终形态**）：近 7 日，把「每个交易日 × 当天出现的每个高度（≥2板）」展开成点、**连成一条折线**。**同日横向错开**（一天占一个槽，当天各层在槽内从左到右排开），**Y 值 = 板数**、**点越高板数越高**、颜色越深（`visualMap` 按板数着色）；**图上数字 = 该层当日股票家数**；某层当天不存在则**不补点，折线直接斜着连过去**（无断口）。**点/悬浮任意点**弹出「日期 + 连板共 N 只 · 最高 X 板 + 该层股票（名称前 3 字·板数·概念）+ 当天全部层级概览」。字段 `ladder[].levels = [{boards, n, list}]`；渲染走 `drawLadderChart()` 的 `levelMode:true` 分支（`type:'value'` 数值轴 + `interval` 对齐槽心）。
  - ⛔ 不是「每层一条平行线」，也不是「同日堆在同一 x 的竖直锯齿」—— 这两种都被用户否掉了
  - ⚠️ 「次高板」这个命名有误导性 —— 用户要的是**完整台阶**，不是「第二个高度」
- **跌停板梯队**（紧接连板高度梯队下方，**同构复用**）：与连板高度梯队**同一套渲染函数** `drawLadderChart()`（连板图传 `levelMode:true` 走单条折线分支，跌停图 **不传** → 走老三条线分支），三条线 = **最高连跌 / 次高连跌 / 创业板**（近 7 日）；**图上数字 = 该梯队股票家数**（如 2 连跌有 2 只 → 标 2；线的 Y 值仍是连跌天数），纵轴只保留整数刻度，**点/悬浮**出「股票名(连跌天数·行业)」+ 当日跌停家数。字段 `data.dt_ladder`（7 日，与 `ladder` 同构）+ `data.dt_pool`（今日明细，含开板次数/封单/换手/概念）。⚠️ 跌停池接口用 `getTopicDTPool` 但 **`dpt` 须写 `wz.ztzt`**（写 `wz.dtzt` 返回 0 条）
- **节点票池**：只保留总市值 ≤ 200 亿；只保留最近 10 个交易日（约两周）的节点
- **失效节点清理**：节点内已无任何连板票（连板中 / 断板反包）时自动删除；当日新节点豁免
- **断板判定**：一路未断板 → `连板中`(≥2板) / `首板`；断板后 ≤3 个交易日重新涨停 → `断板反包`；今天不在涨停池 → `已断板`（UI 折叠）
- **概念抓取**：同花顺 **F10**（`basic.10jqka.com.cn/<码>/concept.html`，GBK）→ 概念名 + 概念ID + 地域 + 申万行业 → 别名归一 → 由榜单热度排出「当下最热概念」；再叠加**同花顺涨停原因**（`block_top.reason_type` / `reason_info`）与事件标签（重组 / 中标 / 业绩预增…）
- **上板分时量**（⚠️ 曾出重大低估 bug，务必按此口径）：取「封板时刻**进位到下一分钟**」那根分时线的**成交额（该分钟增量，不是累计）**。例：闽东电力 `fbt=93024` → 取 **09:31** 那根 = **2.35亿**（硬线 1.17亿）。数据源＝**同花顺分时** `d.10jqka.com.cn/v6/time/hs_<码>/last.js`（字段序 `时间,现价,该分钟成交额(元),均价,该分钟量`）。⚠️ 盘后 15:05–15:30 行尾列可能为空 → 逐行容错。完整说明见 [`项目约定.md`](./项目约定.md) 第 3.5 节

## 五、常见问题

**Q：打开页面提示「未找到 data.js」**
数据还没生成。双击 `refresh.bat` 跑一次即可。

**Q：`refresh.bat` 说 Python not found**
先双击 `setup.bat`；若仍失败，确认 Python 已加入 PATH（命令行输入 `python --version` 验证）。

**Q：拼音缩写是空的（"缩写怎么又丢了"）**
`pypinyin` 没装上（**唯一的第三方依赖**）。⚠️ 缺了不会报错，只会把**全站缩写静默写成空串**。
- 修复：`<你实际跑脚本的python> -m pip install pypinyin`
  —— ⚠️ **本机清华 pypi 镜像不通**（报 `No matching distribution found`）→ **必须用官方源**（不加 `-i`）。
- 装完**必须重跑 `fetch_data.py` + `enrich_tags.py`** 才补得回来（`candidates`/`recommend` 由 fetch_data 的
  「派生字段自愈」自动补）。自检：脚本结尾会打印 `股票缩写(pinyin)：N/M 非空`（正常 >90%）。
- 原理与完整事故复盘见 `项目约定.md` **§9.2 第 17 条**。

**Q：概念抓得不准**
在 `fetch_data.py` 的 `CONCEPT_FIX` 里按代码锁定，例如：
```python
CONCEPT_FIX = {
    '002980': ['CPO', 'AI眼镜', '物联网'],
}
```

**Q：板块「涨停/全部」列显示「—」，或 3日/5日 涨幅为空**
同花顺**板块成分股页 2026-09-20 起被 chameleon JS 反爬拦死（全变体 401）**，该列已改走**东财 push2 板块成分股**。
若个别板块仍为空：确认该板块是否带 `em_code`（**只有「产业板块」清单里的板块有**，行业榜/概念榜的 `em_code` 恒为空串，本就不参与该列渲染）；东财在并发下偶发空响应，重跑一次 `fetch_data.py` 即可。

**Q：`board_kline` 最后一天比看板日期早一天**
同花顺板块日K**盘中不含当日**。收盘后（15:05 之后）重跑 `fetch_data.py`，或单独跑 `python fill_board_kline.py`。

**Q：现在还用东财吗？**
**只剩 2 处**：① 跌停**个股池明细**（`push2ex.eastmoney.com/getTopicDTPool`）—— 同花顺无公开的跌停个股池接口，只有家数；
② **板块成分股（算涨停家数）**（`fetch_data.em_board_zt_count()`，`push2.eastmoney.com/api/qt/clist/get?fs=b:BKxxxx`）
—— 因为同花顺板块成分股页被反爬拦死。
两处都属**未被封的 push2/push2ex 域**（**不是**被按 IP 封禁的 `push2his` 路径）。其余全部走同花顺（统一取数层 `ths_source.py`）。

**Q：`data.json` / `review_data.json` 能删吗？**
**不能**。`review_data.json` 是活的（`fetch_data.py` 实时接口失败时兜底读取）；`data.json` 是 K线合并的上一版基线（`merge_board_kline` 依赖它防覆盖）。
