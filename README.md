# A股短线复盘仪表盘

单页 HTML 仪表盘 + Python 数据管线。四个模块：每日必看 / 梯队复盘 / 重点板块 / 均线共振池。

> ### ⚠️ AI 助手必读
> **动手改任何东西之前，先读仓库根目录的 [`项目约定.md`](./项目约定.md)。**
> 里面是**取数规则**（板块K线/量能＝同花顺，东财已停用；跨域取数一律 script 注入 + 固定回调名）、**业务口径**（上板分时量怎么取、竞价硬线）、**工程纪律**（改完必须验证哪些）、**盘前/盘后分工**、**4 条自动化任务**、**交接话术**。
> 本地 `.workbuddy/memory/` 不入库，**只有仓库里的 `项目约定.md` 是换电脑后仍然有效的**。

- **看板入口（永久链接·推荐）**：https://JIANWANGSAN.github.io/stock-dashboard/ （GitHub Pages 托管，无沙盒休眠；每交易日 **9:26 盘前** + **15:05 盘后**自动更新）
- **看板入口（备用）**：双击 `index.html`，或 WorkBuddy 沙盒链接（由 15:05 任务发布）
- **数据刷新**：双击 `refresh.bat`

## 一、换一台电脑，怎么跑起来（3 步）

> 前提：装了 Python 3.10+（[python.org](https://www.python.org) 下载，安装时**务必勾选 Add Python to PATH**）

1. 把整个文件夹拷到新电脑（或 `git clone` 本仓库）
2. **双击 `setup.bat`** —— 自动建虚拟环境并安装 `pypinyin`（只做一次）
3. **双击 `refresh.bat`** —— 抓数据，完成后打开 `index.html` 即可

数据抓取只依赖 Python 标准库 + `pypinyin`，无其他第三方依赖。

## 三、文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 看板页面（含全部样式与渲染逻辑） |
| `data.js` / `data.json` | 看板数据（由脚本生成） |

| `fetch_data.py` | 主采集：指数/量能、新闻、板块榜、连板梯队、三类节点（**候选池与次日推荐归 9:26 盘前任务**）|
| `enrich_tags.py` | 补齐个股标签（地域/概念/拼音）；**不再重算推荐卡**（归 9:26 盘前任务）|
| `premarket.py` | **盘前任务（每交易日 9:26）**：重算候选池+次日首选 → 抓竞价快照 → 把竞价判定写回每条候选 |
| `auction_check.py` | 竞价合格判定：抓候选票竞价快照并写回 `candidates[].auction_*`（被 premarket.py 调用）|

| `collect_review.py` / `build_review.py` / `save_review.py` | 盘后复盘文本生成与归档 |
| `setup.bat` | 新电脑首次初始化 |
| `refresh.bat` | 刷新数据 |
| `push_api.py` | `git push` 被网络阻断时的兜底推送（走 `api.github.com`，自动对齐本地与远端 SHA）|

## 四、核心口径（改代码前必读）

- **股票池过滤**：一律剔除 北交所（4/8/92 开头）、科创板（688/689）、ST / 退市
- **连板高度梯队**：近 7 日「最高板/次高板/创业板」折线，**图上数字 = 该梯队股票家数**（如 6 板有 1 只 → 标 1；线的 Y 值仍是板数），**点/悬浮任意日期**弹出当天各梯队「股票名(板数·题材)」
- **跌停板梯队**（紧接连板高度梯队下方，**同构复用**）：与连板高度梯队**同一套渲染函数** `drawLadderChart()`，三条线 = **最高连跌 / 次高连跌 / 创业板**（近 7 日）；**图上数字 = 该梯队股票家数**（如 2 连跌有 2 只 → 标 2；线的 Y 值仍是连跌天数），纵轴只保留整数刻度，**点/悬浮**出「股票名(连跌天数·行业)」+ 当日跌停家数。字段 `data.dt_ladder`（7 日，与 `ladder` 同构）+ `data.dt_pool`（今日明细，含开板次数/封单/换手/概念）。⚠️ 跌停池接口用 `getTopicDTPool` 但 **`dpt` 须写 `wz.ztzt`**（写 `wz.dtzt` 返回 0 条）
- **节点票池**：只保留总市值 ≤ 200 亿；只保留最近 10 个交易日（约两周）的节点
- **失效节点清理**：节点内已无任何连板票（连板中 / 断板反包）时自动删除；当日新节点豁免
- **断板判定**：一路未断板 → `连板中`(≥2板) / `首板`；断板后 ≤3 个交易日重新涨停 → `断板反包`；今天不在涨停池 → `已断板`（UI 折叠）
- **概念抓取**：同花顺 **F10**（`basic.10jqka.com.cn/<码>/concept.html`，GBK）→ 概念名 + 概念ID + 地域 + 申万行业 → 别名归一 → 由榜单热度排出「当下最热概念」；再叠加**同花顺涨停原因**（`block_top.reason_type` / `reason_info`）与事件标签（重组 / 中标 / 业绩预增…）
- **上板分时量**（⚠️ 曾出重大低估 bug，务必按此口径）：取「封板时刻**进位到下一分钟**」那根分时线的**成交额（该分钟增量，不是累计）**。例：闽东电力 `fbt=93024` → 取 **09:31** 那根 = **2.35亿**（硬线 1.17亿）。数据源＝**同花顺分时** `d.10jqka.com.cn/v6/time/hs_<码>/last.js`（字段序 `时间,现价,该分钟成交额(元),均价,该分钟量`）。⚠️ 盘后 15:05–15:30 行尾列可能为空 → 逐行容错。完整说明见 [`项目约定.md`](./项目约定.md) 第 3.5 节
- **大盘宏观面板（必看页 · 2026-09-18 改版）**：必看页**只保留置顶「沪深量能」**，其余换成 5 个模块（大盘概览与今日资金主线 / 27 个产业板块涨跌热力网格 / 主力资金行业净流入排行（双向条形）/ 风格轮动强弱 / 3 条行业配置研判）。金融终端风、**涨红跌绿**、中文。
  - 取数：`python macro.py`（3~8s，**盘中盘后都能跑**，实时口径）→ 写 `data.json`/`data.js` 的 `macro` 键；渲染在 `index.html` 的 `renderMacro()`。
    ✅ **已与主流程一体**：`fetch_data.py` 第 **[7/8]** 步会自动调用 macro，盘后**只需跑 `fetch_data.py` 即可**（跳过用 `--no-macro`）；macro 抛错被 try/except 吞掉，不影响主体数据。

  - 预生成失败/残缺时**自动沿用上一版 `board_kline`**（`merge_board_kline`），不会清空。手动补齐：`python fill_board_kline.py`。

- **炸板次数**：候选池「炸板」列，取自**同花顺涨停池** `open_num`（炸板总家数）与 `block_top.stock_list` 的个股开板次数，非 0 即标红——炸板多次是风险标记。注意：硬线取**首次封板**那一根的量能，炸板回封不重复计入。
  - **上板分时量 = 封板那一刻所在「那一根分时线」的成交额**（该分钟增量，**不是累计**）。分钟线标签 = 该分钟区间的**结束**时刻（首根 09:30 = 集合竞价），且源站 `fbt` 的分秒常被截断，故用 `seal_bar_label(fbt)` **一律进位到下一分钟**再取那根。例：闽东电力 `fbt=93024` → 取 09:31 那根 = **2.35亿**（硬线 1.17亿）。⚠️ 旧实现把 `93024` 截成 `09:30`，正好命中集合竞价那根 → 只算出 0.82亿，属重大低估，已于 2026-09-14 修正。⚠️ `fbt` 缺失时从分时反推封板时刻（取现价==当日分时最高价那根）。⚠️ **只有 9:15–9:30 抓到的量额才是竞价口径**（`auction_is_live=true`），其他时段拿到的是全日成交额、不可比 —— 卡片会如实标注。数据源：同花顺分时；快照（今开/量/额/昨收）腾讯 `qt.gtimg.cn` 优先、同花顺 `realhead` 兜底。
- **性能约定**：所有网络抓取一律并发（`ThreadPoolExecutor`）—— 涨停池 4 线程、指数/板块/新闻/量能 4 路并行、涨停原因 4 线程、个股标签 4 线程、模块4 K线 8 线程；`http_get` 超时 **8s**、退避 **0.6+0.6i**（原 15s 超时，网络抖动时单请求可阻塞 45s）。整条管线由 ~130s 降到 **≈15~25s**

## 五、常见问题

**Q：打开页面提示「未找到 data.js」**
数据还没生成。双击 `refresh.bat` 跑一次即可。

**Q：`refresh.bat` 说 Python not found**
先双击 `setup.bat`；若仍失败，确认 Python 已加入 PATH（命令行输入 `python --version` 验证）。

**Q：拼音缩写是空的**
`pypinyin` 没装上。双击 `setup.bat` 重装一次。

**Q：概念抓得不准**
在 `fetch_data.py` 的 `CONCEPT_FIX` 里按代码锁定，例如：
```python
CONCEPT_FIX = {
    '002980': ['CPO', 'AI眼镜', '物联网'],
}
```

**Q：板块「涨停/全部」列显示「—」，或 3日/5日 涨幅为空**
同花顺板块成分股页在并发下会**偶发 403**（瞬时）。已内置第 1 页重试 2 次；若仍有个别板块取不到，重跑一次 `fetch_data.py` 即可。

**Q：`board_kline` 最后一天比看板日期早一天**
同花顺板块日K**盘中不含当日**。收盘后（15:05 之后）重跑 `fetch_data.py`，或单独跑 `python fill_board_kline.py`。

**Q：现在还用东财吗？**
**只剩 1 处**：跌停**个股池明细**（`push2ex.eastmoney.com/getTopicDTPool`）—— 同花顺无公开的跌停个股池接口，只有家数。其余全部走同花顺（统一取数层 `ths_source.py`）。若该接口将来也失效，跌停梯队会降级为「只有家数、无个股明细」。

**Q：`data.json` / `review_data.json` 能删吗？**
**不能**。`review_data.json` 是活的（`fetch_data.py` 实时接口失败时兜底读取）；`data.json` 是 K线合并的上一版基线（`merge_board_kline` 依赖它防覆盖）。
