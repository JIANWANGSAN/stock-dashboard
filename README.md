单页 HTML 仪表盘 + Python 数据管线。四个模块：每日必看 / 梯队复盘 / 重点板块 / 均线共振池。

> 里面是**取数规则**（东财无跨域头 → 必须走 JSONP）、**业务口径**（上板分时量怎么取、竞价硬线）、**工程纪律**（改完必须验证哪些）、**盘前/盘后分工**、**4 条自动化任务**、**交接话术**。
> 本地 `.workbuddy/memory/` 不入库，**只有仓库里的 `项目约定.md` 是换电脑后仍然有效的**。

- **看板入口（永久链接·推荐）**：https://JIANWANGSAN.github.io/stock-dashboard/ （GitHub Pages 托管，无沙盒休眠；每交易日 **9:26 盘前** + **15:05 盘后**自动更新）
- **看板入口（备用）**：双击 `index.html`，或 WorkBuddy 沙盒链接（由 15:05 任务发布）

## 一、换一台电脑，怎么跑起来（3 步）

> 前提：装了 Python 3.10+（[python.org](https://www.python.org) 下载，安装时**务必勾选 Add Python to PATH**）

1. 把整个文件夹拷到新电脑（或 `git clone` 本仓库）
2. **双击 `setup.bat`** —— 自动建虚拟环境并安装 `pypinyin`（只做一次）
3. **双击 `refresh.bat`** —— 抓数据，完成后打开 `index.html` 即可

数据抓取只依赖 Python 标准库 + `pypinyin`，无其他第三方依赖。

## 四、核心口径（改代码前必读）

- **股票池过滤**：一律剔除 北交所（4/8/92 开头）、科创板（688/689）、ST / 退市
- **节点票池**：只保留总市值 ≤ 200 亿；只保留最近 10 个交易日（约两周）的节点
- **失效节点清理**：节点内已无任何连板票（连板中 / 断板反包）时自动删除；当日新节点豁免
- **断板判定**：一路未断板 → `连板中`(≥2板) / `首板`；断板后 ≤3 个交易日重新涨停 → `断板反包`；今天不在涨停池 → `已断板`（UI 折叠）
- **概念抓取**：全量东财板块 → 剔除噪声 / 地域 / 行业大类 → 别名归一（如 光通信模块 → CPO）→ 按板块当日涨幅排序取「当下最热概念」；再叠加新闻事件（重组 / 中标 / 业绩预增…）
- **上板分时量**（⚠️ 曾出重大低估 bug，务必按此口径）：取「封板时刻**进位到下一分钟**」那根分时线的**成交额（该分钟增量，不是累计）**。例：闽东电力 `fbt=93024` → 取 **09:31** 那根 = **2.35亿**（硬线 1.17亿）。完整说明见 [`项目约定.md`](./项目约定.md) 第 3.5 节
- **沪深量能**（必看置顶柱状图）：`量能 = 上证综指 + 深证综指 的日成交额`（**不含北交所**），取近 15 个**已收盘**交易日；数据源东财 `push2his` 日K `f57`（成交额,元），接口偶发 `RemoteDisconnected`，已改为**两市场并行 + 有界重试**；柱色 红=较昨日放量 / 绿=缩量，橙色虚线=3万亿；盘中当日不纳入。字段 `data.js → market_volume = {list:[{date,amount_yi}], date, total_yi}`
- **板块发酵**（候选池「发酵」列）：候选题材概念 × 当日涨停池细分行业(东财 `hybk`) 模糊匹配命中的涨停家数/连板数。注意东财 `hybk` **被截断为 ≤4 字**（旅游及景区→旅游及景），故匹配放宽为「整串互相包含 + **前 2 字词干**互相包含」，并把候选自身细分行业也纳入比对 —— 否则发酵列会长期假 0
- **消息速览**：只显示「**完整句**的简述」（源站摘要常被截断，故后端 `news_brief()` 按句号只取完整句，拼到 ≈72 字；全无完整句则回退标题）。字段 `news[k][].text`
- **个股点击看行情**：页面股票名（节点票/触发股/首选/候选池/模块4）带 `data-scode`，点击弹层展示 **当日分时 / 日K线**。取数**腾讯源优先**（`web.ifzq.gtimg.cn`，返回 `Access-Control-Allow-Origin: *`，跨域兼容最好）→ **东财 `push2his` 兜底（必须 JSONP —— 东财不返回跨域头，`fetch` 会被 CORS 拦）**；前端直连，无需后端代理。模块3 板块「领涨股」只有名称无代码，暂不可点
- **盘前 / 盘后分工（重要）**：「梯队」菜单顶部的**「我的想法·次日连板推荐」与「连板候选池」**属**盘前内容**，由 `premarket.py` 在每交易日 **9:26**（竞价 9:25 定格后）刷新；盘后 `fetch_data.py` **不再重算**这两块，只沿用上一版（`enrich_tags.py` 也不再重算推荐卡）。其余全部内容（指数/量能/新闻/板块/梯队/节点/模块4）仍是 **15:05 盘后**刷新。数据天然互通：候选池每条票自带硬线与竞价判定，不需要单独的竞价卡。
- **竞价判定（并入候选池）**：候选池「竞价硬线」「竞价结论」两列。口径 `竞价额 ≥ 该票「上板分时量 × 50%」` 为**合格**；硬线字段 `bid_required_yi`（**全量候选都算**，6 线程并发 + 当日缓存；只有分时取数失败才回退 `全天成交额×50%`，回退时该格悬浮提示会标出 `bid_basis`）；判定结果写回每条候选 `auction_amt_yi` / `auction_ok` / `auction_open` / `auction_pct`，`auction_is_live` 标记是否为真竞价口径。
- **板块榜口径：只用东财，且与「东方财富 App → 行情 → 板块」逐条对齐**（2026-09-15 用 App 截图逐项比对验证）：
  - **行业榜 = 申万二级行业**：东财 `m:90+t:2` 共 496 个板块（含一级与三级细分），必须只保留**二级**才与 App 一致。
    判据 `is_l2_industry(code)`：排除申万一级（`BK1200~BK1217` 连续段，外加 公用事业/农林牧渔/纺织服饰/煤炭/食品饮料/家用电器/石油石化/有色金属/钢铁/传媒/环保/美容护理/银行 等 13 个，共 **31 个**，见 `L1_BOARD_CODES`）、排除三级细分与东财自建（`BK1289+`、`BK13xx~BK17xx`）。
    ⚠️ 不这样做的话，「钨 / 风电零部件 / 半导体设备 / 门户网站」这类细分会顶掉真正的行业（如「风电设备」）。
  - **概念榜 = 东财 `m:90+t:3`**，剔除**风格类**板块（`STYLE_BOARD_KW`：昨日连板 / 反转股 / 科技风格 / 融资融券 / 次新股…）——App 把这类归「风格」tab。
    ⚠️ 概念榜**只在数据层**（`data.js → board_concept`），**页面不展示**；它供盘前任务的「题材共振」匹配候选题材用。
  - 字段：`name / code(BKxxxx) / pct(当日 f3) / d3(3日 f127) / d5(5日 f109) / up / down / leader / leader_pct / zljlr_wan / em_code`。
  - **3日榜直接用东财 `f127`（3日涨跌幅）**，与 App「3日」同口径（元件6.43 / 风电设备3.52 / 玻璃玻纤2.89 / 电子化学品Ⅱ2.82 / 半导体-0.19 逐条吻合）；**不再自建历史快照**（`board_history.json` 已废弃）。
  - **「涨停/全部」列**：拉每个板块的成分股（东财 `fs=b:BKxxxx`）逐只判涨停 —— 科创/创业板 20%、主板 10%、ST 5%，**已剔除北交所**（与全局股票池规则一致）。板块「涨停家数」东财列表接口不提供，必须这样算。
  - 为什么换掉腾讯：腾讯板块过细且常有生僻名（如「华为汽车股权合作」「口含烟」），且**腾讯板块K线只返回当日 1 根**；换东财后**板块名 = 板块K线代码 = 成分股 = 个股概念标签同源**，不再需要「腾讯名→东财名」映射。
- **页面展示**：「行业涨幅榜 · 当日 TOP10」+「行业涨幅榜 · 3日 TOP10」两张表，两榜**重合标 ★**（持续性最强方向）；两表均带 **「涨停/全部」**列。
- **板块K线（板块名可点击）**：模块3 两个榜的**板块名都可点**，弹出**日K / 周K + MA5/MA10/MA20**（东财板块指数 `secid=90.BKxxxx`，klt=101日/102周）。
  - ⚠️ **改为「盘后预生成」**：浏览器直连东财取板块K线**跨域不可靠**（`push2his` 无 CORS 头，JSONP 时好时坏，实测手机上会一直失败）。
    现改为 `fetch_board_klines()` 在盘后把榜单板块的 **日K120根 + 周K60根** 抓好、写进 `data.js → board_kline`，前端点击**直接读本地数据**（秒开、可离线）；本地没有该板块时才走网络兜底，再失败给「点此在东方财富查看该板块」链接。
  - **取数必须加时间戳参数 `&_=<ms>`**：不加时对**同一 URL 连续请求会被限流**（表现为 `http_get` 返回 None），加了立即恢复。这是本次补齐 13 个板块时的关键踩坑。
  - 预生成失败（东财限流）时**沿用上一版 `board_kline`**，不会清空。手动补齐：`python fill_board_kline.py`（增量、可反复运行）。
  - ⚠️ **必须走 JSONP**：东财 `push2his` **不返回 `Access-Control-Allow-Origin`**，浏览器 `fetch` 直连会被 CORS 拦（这正是早期「点开空白 / 加载失败」的根因，股票行情弹层当初也是因此改用腾讯源）。
    故板块K线改用 **JSONP**（`&cb=<callback>`，东财支持该参数，返回 `cb({...})`）注入 `<script>` 取数——**不受同源策略限制**；JSONP 失败才回退直连 `fetch`。
  - 站点无 CSP、`sw.js` 对跨域请求一律放行（`url.origin !== self.location.origin → return`），故 JSONP 不被拦截。

- **炸板次数**：候选池「炸板」列，取自东财涨停池 `zbc`（当日炸板次数），非 0 即标红——炸板多次是风险标记（如闽东电力 2 次、桂林旅游 8 次）。注意：硬线取**首次封板**那一根的量能，炸板回封不重复计入。
  - **上板分时量 = 封板那一刻所在「那一根分时线」的成交额**（该分钟增量，**不是累计**）。分钟线标签 = 该分钟区间的**结束**时刻（首根 09:30 = 集合竞价），且源站 `fbt` 的分秒常被截断，故用 `seal_bar_label(fbt)` **一律进位到下一分钟**再取那根。例：闽东电力 `fbt=93024` → 取 09:31 那根 = **2.35亿**（硬线 1.17亿）。⚠️ 旧实现把 `93024` 截成 `09:30`，正好命中集合竞价那根 → 只算出 0.82亿，属重大低估，已于 2026-09-14 修正。⚠️ **只有 9:15–9:30 抓到的量额才是竞价口径**（`auction_is_live=true`），其他时段拿到的是全日成交额、不可比 —— 卡片会如实标注。数据源：东财 `push2` 快照（f46今开/f47量/f48额/f60昨收），腾讯 `qt.gtimg.cn` 兜底。
- **性能约定**：所有网络抓取一律并发（`ThreadPoolExecutor`）—— 涨停池 4 线程、指数/板块/新闻/量能 4 路并行、涨停原因 4 线程、个股标签 4 线程、模块4 K线 8 线程；`http_get` 超时 **8s**、退避 **0.6+0.6i**（原 15s 超时，网络抖动时单请求可阻塞 45s）。整条管线由 ~130s 降到 **≈15~25s**

## 五、常见问题

**Q：打开页面提示「未找到 data.js」**
数据还没生成。双击 `refresh.bat` 跑一次即可。

**Q：`refresh.bat` 说 Python not found**
先双击 `setup.bat`；若仍失败，确认 Python 已加入 PATH（命令行输入 `python --version` 验证）。

**Q：拼音缩写是空的**
`pypinyin` 没装上。双击 `setup.bat` 重装一次。

**Q：概念抓得不准**
在 `fetch_data.py` 的 `CONCEPT_FIX` 里按代码锁定，例如：
```python
CONCEPT_FIX = {
    '002980': ['CPO', 'AI眼镜', '物联网'],
}
```
